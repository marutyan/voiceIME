# VoiceIME（macOS メニューバー常駐アプリ）

キーを押している間だけ録音し、離すと別プロセスの認識エンジン（`python -m voiceime.engine`）で文字起こし・整形した文を、いまカーソルのあるアプリへ貼り付ける macOS 常駐アプリです。

## 動作要件

- Apple Silicon Mac（macOS 14 以降）
- Xcode Command Line Tools（Swift 6.0 以降）
- `uv` と voiceIME リポジトリの Python 認識エンジン環境（`docs/engine-protocol.md` 参照）

## ビルドとテスト

この `app/` ディレクトリで実行します。

```bash
# テストを実行する
swift test

# リリース実行ファイルをビルドする
swift build -c release

# .app バンドルを生成して ad-hoc 署名する（出力先: app/build/VoiceIME.app）
./scripts/build-app.sh
```

出力先を変えたい場合は `--out-dir` を指定できます。

```bash
./scripts/build-app.sh --out-dir /Applications
```

起動は Finder から `VoiceIME.app` を開くか、ターミナルで次を実行します。

```bash
open build/VoiceIME.app
```

起動時、アプリは子プロセスとして `uv run --project <リポジトリ> python -m voiceime.engine` を起動します。`<リポジトリ>` のパスはビルド時に `Info.plist`（`VoiceIMEProjectRoot`）へ埋め込まれます。別の場所にあるリポジトリや `uv` を使いたい場合は、環境変数 `VOICEIME_PROJECT_DIR` と `VOICEIME_UV_PATH` で上書きできます。

## 必要な権限の設定

初回起動時または権限不足時に、不足している必須権限と許可する場所を通知します。音声入力の基本動作には以下の 3 つを許可してください。

1. **マイク**（音声の録音に必要）
   - 「システム設定 > プライバシーとセキュリティ > マイク」で `VoiceIME` をオンにします。
2. **アクセシビリティ**（録音開始時と貼り付け直前の入力先・フォーカス照合、および ⌘V 送信に必要）
   - 「システム設定 > プライバシーとセキュリティ > アクセシビリティ」で `VoiceIME` を追加してオンにします。
3. **入力監視**（`fn` キーや `Control + Option + Space`、`Esc` の監視に必要）
   - 「システム設定 > プライバシーとセキュリティ > 入力監視」で `VoiceIME` を追加してオンにします。

### 任意の権限：画面収録（画面の文字を用語のヒントに使う場合）

録音開始時に前面ウィンドウの文字を Vision で読み取り、論文・コード・チャット上の技術用語を認識エンジンへヒントとして渡す機能（「画面の文字を使う」、既定はオン）を有効にするには、次の権限を許可してください。

4. **画面収録**（任意：未許可でも `screen_text` なしで音声入力自体はそのまま動きます）
   - 「システム設定 > プライバシーとセキュリティ > 画面収録とシステムオーディオ録音」（macOS の版によっては「画面収録」）を開く。
   - リストに `VoiceIME` が無い場合は、メニューバーの VoiceIME アイコンから **「画面収録の権限を確認...」** を選ぶか、システム設定の「+」から `VoiceIME.app` を追加してオンにする。
   - 撮影したウィンドウ画像はメモリ上だけで文字認識し、ディスクには保存しません。読み取った画面の文字は認識履歴（`history.jsonl`）にも保存しません。

アクセシビリティ、入力監視、画面収録を許可した後は、`VoiceIME.app` を一度終了して再起動すると確実に反映されます。

## macOS の「🌐キーを押して：何もしない」設定

既定の起動キーである **fn（🌐）キー長押し** を使うには、macOS 標準の絵文字ピッカーや入力ソース切り替えが立ち上がらないよう、次の設定を変更してください。

1. 「システム設定 > キーボード」を開く。
2. **「🌐キーを押して」**（環境によっては「fnキーを押して」）を **「何もしない」** に設定する。

他の用途で 🌐 キーを使いたい場合は、メニューバーの VoiceIME アイコンから起動キーを **「Control + Option + Space で開始/停止」** へ切り替えられます。録音中に **Esc** を押すと、その録音を取り消します。

## メニューバーのアイコンと操作

- **アイコンの状態**
  - マイク枠線：待機中
  - 赤い塗りつぶしマイク：録音中
  - 波形：認識エンジンの起動中、または認識・整形の処理中
  - オレンジの警告アイコン：認識エンジンの異常終了や起動設定エラー
- **メニュー項目**
  - 起動キーの切り替え（`fnキーを押している間録音` / `Control + Option + Space で開始/停止`）
  - `録音中の表示（オン / オフ）`（クリックで画面下中央ピルの表示を切り替え、既定はオン）
  - `画面の文字を使う（オン / オフ / 権限なし）`（クリックでオン／オフを切り替え、既定はオン。権限なし時は `画面収録の権限を確認...` も表示）
  - `最後の結果をもう一度貼る`
  - `終了`

### 録音中・処理中の画面表示（画面下中央ピル）

「録音中の表示」がオンのとき、前面スクリーンの下中央（Dock の上）に小さなピルを表示します。待機時は非表示です。

- **録音中**：赤い脈動ドット、マイク音量に連動する波形バー、経過秒を表示します。認識エンジンから途中結果（`partial`）が届くと幅 300pt（最大2行、超過分は末尾省略）へ上方向に広がります。
- **処理中**：スピナーと「整形中…」を表示します。
- **完了**：緑のチェックマークを表示し、約 0.9 秒で自動的にフェードアウトして消えます。
- **エラー**：赤ティントと短い理由を表示して自動的に消えます（詳細は macOS 通知で案内します）。
- **操作を妨げない設計**：非アクティブパネルかつクリック透過で表示するため、入力中のアプリのフォーカスや IME 変換状態、裏側にある画面要素のクリック操作を奪いません。

## 既知の制限

- **ad-hoc 署名による権限の再登録**：`./scripts/build-app.sh` は `codesign --sign -`（ad-hoc 署名）を行います。再ビルドするとバイナリの署名ハッシュが変わるため、macOS の「アクセシビリティ」「入力監視」「マイク」「画面収録」の許可が外れた扱いになることがあります。反応しない場合は、システム設定の該当リストから `VoiceIME` を一度削除（`-`）して登録し直してください。
- **認識エンジンの起動待ち**：起動直後や異常終了後の自動再起動中は、エンジンから `ready` を受け取るまで録音を開始しません。
- **セキュア入力欄や一部アプリでのフォーカス取得**：パスワード欄など macOS のセキュア入力が有効な状態や、`AXFocusedUIElement` を公開していないアプリでは、フォーカス要素単位の照合ができず前面アプリの PID のみで照合します。また、セキュア入力中は `CGEventTap` にキーイベントが届かない場合があります。
- **外付けキーボードの fn キー**：一部の他社製外付けキーボードでは fn キーがハードウェア内で完結し、macOS へ `flagsChanged` を送らないことがあります。その場合はメニューから「Control + Option + Space で開始/停止」を選んでください。
- **貼り付け先が変わった場合の挙動**：録音開始時と貼り付け直前で前面アプリまたはフォーカス要素が変わっていた場合、誤爆防止のため貼り付けは行わず、認識結果をクリップボードへコピーして通知します。
