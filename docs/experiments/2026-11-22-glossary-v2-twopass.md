## 分析

- **用語は増えなかった**。読み上げ50件の用語67回はすべて第1版にもある語なので、このデータでは第2版は正しい候補を増やせず、競合する候補だけを増やす。結果は、どの条件でも用語の正答率が下がった（ASR直後44→38〜41、整形後56→51〜52）。第2版の利点を測れるのは、第1版に無い語を話すデータ（自由発話、`test-novel`）だけである。
- **下がった原因は、候補の押し出し**。選択（`select_glossary`）は、読みの一部がカタカナの区間に一致すれば点数を100にする。第2版には「Memory」「Model」「Dialog」のように一般の語の読みを含む長い語が多く、「メモリ」「モデル」「ログ」を含む発話では、それらが点数100で並び、選択の上限20語とヒントの上限を埋める。そのため、第1版ならヒントに入っていた正解（s028`Anthropic`、s041`Secrets Manager`、s047`QueryDet`）が押し出された（例：s047の選択は`Averaged Gradient Episodic Memory`、`Dynamic Memory Network`など）。押し出す語の点数が100なので、閾値を90や100に上げても防げない（閾値90と100のヒントは100件中94件で同じ）。
- **誤挿入の数はほぼ同じだが、中身が変わった**。ASR直後の補助の数は22→16〜20で、第2版の新しい語（`Attention Flow`、`MLflow Projects`、`Multus`、`validation_data`）が入った。整形後は、s006の「anyway、これは今のプロジェクト」が`MLflow Projects`に、s028の`Anthropic`が`Android Studio`に置き換わり、CERは6.31%→7.72〜9.82%に上がった。用語集の第2版には一般の語（プロジェクト、バリデーション）を含む語が多く、整形LLMがそれを用語として当てはめる。
- **切り分け**：ASRだけ第2版にしても、整形が第1版の用語集なら整形後は56/67、CER6.69%で、今の構成とほぼ同じだった。整形だけ第2版にした場合は55/67、6.82%。両方を第2版にすると51/67、9.82%と大きく悪化する。ASRで落とした語を整形が第1版の用語集で戻せていたのが、整形も第2版にすると戻せなくなる。
- **遅延が約2倍になった**。用語の選択は全語を毎回採点するため、31,415語では1回あたり中央値0.18秒（第1版は0.008秒、`select_glossary`だけを手元で測定）かかる。two-passの選択と整形の選択で2回呼ぶので、合計遅延の中央値が0.44秒→0.76〜0.83秒、p90が0.61秒→1.16〜1.23秒になり、目標の1.0秒をp90で超える。
- **ヒントの上限と閾値**：上限8語は、整形後のCER（7.72〜8.49%）と誤挿入（整形3）が上限16語より少し良いが、用語の正答率は同じか低い（ASR直後38/67）。閾値90は75より整形後の用語が1回多いだけで、100は90とほぼ同じ。第2版のままでは、どの組み合わせも第1版の今の構成を超えない。50件・67回では、条件間の1〜2回の差は誤差の範囲である。
- **自由発話**：第2版で初めて正しく書けた語（`Shadow DETR`、`num_workers`、`AP`、`FP`、`Miss Rate`）があり、第2版の狙いの効果は出ている。一方で、一般の言い回し（デファクトスタンダード、アフィン変換、ディテクションTransformer）が第2版の語に置き換わる例も同じくらいある。

## 分かったこと

- 用語集の第2版をそのままtwo-passと整形へ入れると、読み上げ50件では用語の正答率が83.6%→76〜78%に下がり、CERが上がり、遅延が約2倍になる。今の構成のまま置き換えるべきではない。
- 原因は、閾値ではなく選択の採点の仕方（読みの一部一致で100点になり、長い語が大量に並ぶ）と、1回ごとに全語を採点する計算量にある。ヒントの上限と閾値の調整では直らない。
- 第2版の語を使うには、(1) 部分一致の点数を語の長さに対する一致の割合で下げる、または読みの全体が一致した語を優先する、(2) 第1版の語を優先して選び、第2版の語は残りの枠に入れる（`select_glossary_with_priority`と同じ形）、(3) 読みの索引を前もって作り、毎回の全語の採点をやめる、のいずれかが要る。これは提案で、未検証である。
- 第2版の利点は自由発話や`test-novel`のような第1版に無い語のデータでしか測れない。読み上げ50件は、第2版による悪化（押し出しと誤挿入）を測るのに使う。
