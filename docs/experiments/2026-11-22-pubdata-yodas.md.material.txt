- **CER**：Unicode NFKC正規化、英字の小文字化、句読点と空白の除去を行った後の、文字単位の編集距離÷正解の文字数。2026-11-22から、同じ語の書き方の違い（「パーセント」と「%」、「とき」と「時」）は誤りに数えない（本人の承認。一覧は`src/voiceime/eval/metrics.py`の`CER_EQUIVALENT_FORMS`）。整形の出力は、数字の直後の「パーセント」を「%」で書く（本人の希望。`src/voiceime/formatter/style.py`）。
- **ASR単体のCER**：正解は`spoken_text`とする。ただし用語をカタカナで書くか英字で書くかの差で値が変わらないよう、正解と出力の両方で、その行の`glossary`の`surface`（大文字小文字を区別しない）を最初の`readings`へ置き換えてからCERを計算する（「読み揃えCER」）。整形後（`stage: e2e`）のCERは`target_text`を正解とし、読み揃えはしない。
- **用語の正答率**：正解文に含まれる用語のうち、出力に正確な表記（大文字小文字を含む）で現れた割合。ASR単体の評価では、カタカナ読みでの一致を「緩い正答率」として別に出す。
- **見えない用語の正答率**：推論時に用語集から除いた語（`--exclude-terms`で指定し、ASRのヒントにも整形LLMの参考にも渡さない語）だけを対象にした用語の正答率。正解文の`terms`に現れる語からseed 0で30%を選んで一覧を作り、評価（`voiceime.eval.report --unseen-terms`）では「見えない用語」と「それ以外」に分けて同じ定義（厳密表記、ASR単体では緩い正答率も併記）で算出する。

def select_glossary(
    text: str,
    entries: list[GlossaryEntry],
    max_entries: int = DEFAULT_MAX_ENTRIES,
    min_score: float = DEFAULT_MIN_SCORE,
) -> list[GlossaryEntry]:
    """ASRの出力`text`に近い語を類似度の高い順に最大`max_entries`件選ぶ。同点は用語集の順を保つ。"""
    kana_runs = _text_runs(text, "kana", ignore_long_vowel=True)
    latin_runs = _text_runs(text, "latin")
    scored = [(score_entry(entry, text, kana_runs, latin_runs), i, entry) for i, entry in enumerate(entries)]
    kept = sorted((s for s in scored if s[0] >= min_score), key=lambda s: (-s[0], s[1]))
    return [e for _, _, e in kept[:max_entries]]

def asr_hints(glossary: list[GlossaryEntry], hint_format: str) -> list[Term] | None:
    """用語のsurfaceと最初のreadingを最大16語・240文字までASRへ渡す。"""
    hints: list[Term] = []
    for entry in glossary:
        if any(term.surface == entry.surface for term in hints) or len(hints) >= ASR_GLOSSARY_MAX_TERMS:
            continue
        reading = entry.readings[0] if entry.readings else ""
        if hint_format == "surface-reading" and not reading:
            continue
