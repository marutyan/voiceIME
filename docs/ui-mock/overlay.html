  • 処理中 / 完了 / エラー78×24 / 24×24 / 最大204×24 px

4. 実装時の前提（他アプリの作業を邪魔しない設計）

案A・案Bを採用する場合、表示は前面アプリの入力を妨げない次の条件で実装する前提です。

フォーカスを奪わない

NSPanel に .nonactivatingPanel を設定し、canBecomeKey = false・canBecomeMain = false とします。表示・非表示の切り替えで入力先アプリのフォーカスやIME変換中状態が外れず、既存の宛先照合（PasteController）にも影響しません。

クリックを通す（操作を遮らない）

オーバーレイウィンドウ全体に ignoresMouseEvents = true を設定します。ピルやバッジの裏側にあるテキスト・ボタン・スクロールバーをそのままクリックやドラッグできます。

最前面表示・自動消去・フォールバック

level = .floating と collectionBehavior（全操作スペース・フルスクリーン補助）で控えめに表示し、待機時は非表示・完了チェックは約0.9秒で自動消去します。案Bでテキストカーソル座標（AXBoundsForRange）が取れないアプリでは、マウス付近または画面下中央へ退避します。
