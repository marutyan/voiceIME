## 分析と残り

mainの選び方ではtest-novelのSFT2 baselineが報告値どおり225/500に戻り、Bは243/500となった。以前の168〜186/500という結論は旧一覧による条件差を含んでいた。B/C/B-2Bの配列はSFT2と一致しないため、保存済みSFT2一覧をIDごとに固定した優先度05の再評価を別出力先へ投入した。no-unseenの本人評価では比較baselineがない。

新しい学習条件はdrop 0 / distractors 8、drop 0.15 / distractors 0、drop 0 / distractors 0の3通り。2条件が同じ`mha_graph.execute`のSDPA/cudnnエラーでstep 1,304/5,996に失敗し、残る条件は実行中。再実行は全条件でcuDNN SDPAを無効にし、同じPyTorchの他backendを使う。backend変更の影響は新しい実験条件として記録し、失敗した出力は再利用しない。
